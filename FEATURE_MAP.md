# ClaudeUsage — Feature Map

ClaudeUsage is a single-target Swift Package macOS menubar app that displays how much of your Claude usage quota you've burned. It runs its own OAuth (authorization-code + PKCE) login against Anthropic, stores tokens in a dedicated `ClaudeUsage-credentials` Keychain item (isolated from Claude Code's own item so it can rotate tokens on a 429 without racing the `claude` CLI), polls `https://api.anthropic.com/api/oauth/usage` every 300 s, and renders the percentage used in the current 5-hour session in the menubar — color-coded along a green→red gradient. A SwiftUI popover breaks down the 5-hour, weekly, and per-model (Opus/Sonnet/Fable) windows with countdowns, time-elapsed ticks, and a weekly pacing analysis, plus a button that opens a separate resizable "Usage Breakdown" window apportioning that usage across local projects/sessions by scanning `~/.claude/projects` transcripts. A headless `--json` CLI mode serves the same data (cache-first) to other programs. An alert-only update check tells you when `main` has moved ahead of your build, and a single-instance lock keeps duplicate menubar items from stacking. The app stays out of the Dock (`LSUIElement` + `.accessory`) and is built/installed via stable self-signed code signing to keep its Keychain ACL sticky.

## Feature areas

### Auth
- **PKCE challenge generation** — RFC 7636 verifier+S256 challenge from 32 random bytes (`SecRandomCopyBytes`), base64url-encoded; the verifier is reused as the OAuth `state` parameter per Anthropic's flow quirk. `Sources/ClaudeUsage/PKCE.swift`
- **OAuth authorization-code exchange** — builds the authorize URL (`claude.ai/oauth/authorize`) with PKCE challenge, `client_id`, scopes (`user:profile user:inference`), and `code=true`; `OAuth.exchange` splits a pasted `CODE#STATE` on `#`, POSTs to the token endpoint (`platform.claude.com/v1/oauth/token`), decodes `TokenResponse`, and captures Cloudflare cookies. `Sources/ClaudeUsage/OAuth.swift`
- **Token refresh and rotation** — `OAuth.refresh` POSTs a `refresh_token` grant; `OAuth.refreshAndPersist` rotates access+refresh tokens, computes `expiresAtMs` from `expires_in`, and writes back via `AppCredentials.save`. Shared by the menubar store (proactive near-expiry / reactive 401 / 429 rotation) and CLI mode. `Sources/ClaudeUsage/OAuth.swift`, `Sources/ClaudeUsage/AppCredentials.swift`
- **`invalid_grant` auto-disconnect** — HTTP 400 from the token endpoint with body `{"error":"invalid_grant"}` (refresh token revoked / expired beyond reuse) throws the typed `OAuth.RefreshError.invalidGrant`, distinct from generic `.http(400, …)`. `UsageStore.refresh()` catches it, logs to stderr, and calls `autoDisconnect(reason:)` which wipes the keychain item and sets `reconnectReason` so `ConnectAccountView` renders an orange banner ("Your previous session expired. Please reconnect.") above the connect flow instead of looping on a dead refresh token. The pure decision lives in `OAuth.isInvalidGrantBody(_:)` (only the canonical lowercase `invalid_grant` triggers; other OAuth errors stay surfaced as errors). `Sources/ClaudeUsage/OAuth.swift`, `Sources/ClaudeUsage/UsageStore.swift`, `Sources/ClaudeUsage/ConnectAccountView.swift`
- **App-owned Keychain credential storage** — `AppCredentials` is the sole writer of the dedicated `ClaudeUsage-credentials` (`kSecClassGenericPassword`) item via direct `SecItem` APIs (no `/usr/bin/security` shellout): `SecItemCopyMatching` reads, `SecItemUpdate`+fallback `SecItemAdd` (with `kSecAttrAccessibleAfterFirstUnlock`) writes, `SecItemDelete` on `clear()`. JSON shape mirrors Claude Code's `claudeAiOauth.{accessToken,refreshToken,expiresAt}`. `Sources/ClaudeUsage/AppCredentials.swift`
- **Token expiry tracking and proactive refresh gating** — `ClaudeCredentials.isExpired(slack:)` converts `expiresAtMs` to a `Date` and returns true if `now+slack >= expiry` (default 60 s slack), letting `UsageStore` refresh before a 401. `Sources/ClaudeUsage/Keychain.swift`
- **Legacy Claude Code Keychain reader** — `Keychain` reads the shared `Claude Code-credentials` item via a `/usr/bin/security` shellout and exposes `updateOAuth`. Not used at app runtime; its `ClaudeCredentials` and `KeychainError` types are reused by `AppCredentials`. `Sources/ClaudeUsage/Keychain.swift`
- **Connect Account UI** — two-step SwiftUI popover shown when `UsageStore.needsConnection` is true: opens the authorize URL in the browser, then takes a pasted `CODE#STATE` and exchanges it (spinner while in-flight). On success saves tokens and calls `store.onConnected()`; on failure shows a red caption and regenerates a fresh PKCE pair (codes are single-use). Also renders `store.reconnectReason` as an orange banner above the steps when the app auto-disconnected the user (e.g. revoked refresh token). `Sources/ClaudeUsage/ConnectAccountView.swift`

### Networking / Cache
- **Usage API fetch** — `GET /api/oauth/usage` with Bearer token, `anthropic-beta: oauth-2025-04-20`, `Accept: application/json`, and the `claude-cli` User-Agent; 15 s timeout. On 429 parses `Retry-After` / `anthropic-ratelimit-requests-reset`, floors the wait at 15 s, and throws `UsageAPIError.rateLimited`; non-2xx throws `.http`, transport errors `.transport`. On success calls `CookieJar.captureFromSharedStorage()` then decodes `UsageResponse`. `Sources/ClaudeUsage/UsageAPI.swift`
- **Rate-limit header parsing and logging** — `parseRateLimit(_:)` extracts `anthropic-ratelimit-requests-remaining/limit/reset` (RFC3339 or seconds-from-now fallback) into `RateLimitInfo`; `logRateLimit(status:info:http:)` writes a diagnostic line to `UsageAPI.logHandle` (stdout by default, stderr in `--json` mode). `Sources/ClaudeUsage/UsageAPI.swift`
- **User-agent construction** — `UserAgent.string` lazily builds `claude-cli/<CFBundleShortVersionString> (ClaudeUsage menubar)`; the `claude-cli` prefix is required because Cloudflare's WAF returns 403 for the default `URLSession` UA. Falls back to `0.0.0` when no bundle version (e.g. `swift run`). `Sources/ClaudeUsage/UserAgent.swift`
- **Cloudflare `_cfuvid` cookie persistence** — `CookieJar` persists the CF session cookie across launches via `UserDefaults` (`anthropic._cfuvid.v1.value`/`.savedAt`); `restore()` re-injects it (synthetic far-future expiry, skips cookies older than 24 h) before any `URLSession` use, and `captureFromSharedStorage()` recaptures rotated values after each success. `Sources/ClaudeUsage/CookieJar.swift`
- **On-disk usage cache** — `UsageCache` persists the last successful `UsageResponse` as a JSON `Envelope{response, fetchedAt}` (ISO8601) at `~/Library/Application Support/ClaudeUsage/last_usage.json`; `load()` returns `(response, fetchedAt)?`, `save(_:at:)` writes atomically. Used by the menubar for instant-on data and by `--json` mode as the cache-first layer. `Sources/ClaudeUsage/UsageCache.swift`
- **UsageResponse and window model** — decodes `five_hour`, `seven_day`, `seven_day_opus`, `seven_day_sonnet` (optional `UsageWindow`), `extra_usage` (optional `ExtraUsage`), and the `limits` array (optional `[UsageLimit]`); `UsageWindow.freshUtilization(now:)` returns utilization only when `resets_at` is in the future, guarding against stale cached data. `Encodable` conformances added for cache round-trips (including `limits`). `Sources/ClaudeUsage/UsageAPI.swift`, `Sources/ClaudeUsage/UsageCache.swift`
- **Scoped per-model windows via `limits[]`** — the API moved per-model weekly usage into the `limits` array (each entry has `kind`/`group`/`percent`/`resets_at`/`scope`); the `seven_day_opus`/`seven_day_sonnet` keys now come back null. `UsageResponse.scopedWeeklyWindow(modelDisplayName:)` finds the `kind == "weekly_scoped"` entry whose `scope.model.display_name` matches (e.g. "Fable") and surfaces it as a synthetic `UsageWindow`, so it renders and reports through the same path as the legacy per-model windows. `UsageStore.sevenDayFable` wires this to "Fable". `Sources/ClaudeUsage/UsageAPI.swift`, `Sources/ClaudeUsage/UsageStore.swift`

### App Core & State
- **App entry and dispatch** — `ClaudeUsageMain.main()` restores the `_cfuvid` cookie via `CookieJar.restore()`, then on `--json` calls `CLI.runAndExit()` (never touching `NSApplication`); otherwise creates the shared `NSApplication`, sets `.accessory` policy (no Dock icon), assigns `AppDelegate`, and runs the loop. `Sources/ClaudeUsage/App.swift`
- **NSStatusItem menubar title rendering** — `AppDelegate.updateStatusItemTitle()` reads `UsageStore.menubarLabel` (text, `NSColor`, filled) each time `objectWillChange` fires (hopped one runloop tick). `filled=true` draws a rounded color-block pill with contrasting text (Rec.601 luma via `contrastingText()`); `filled=false` sets a gradient-colored `NSAttributedString` title. `Sources/ClaudeUsage/AppDelegate.swift`
- **Custom borderless panel (popover replacement)** — `AppDelegate` replaces `NSPopover` with a `PopoverPanel` (`NSPanel`, `canBecomeKey=true`): `NSVisualEffectView` (`.menu`) masked with a rounded-rect image plus a light-mode `NSBox` tint, animated open/close, placed via `panelOrigin()` (clamped on-screen) to avoid `NSPopover`'s Tahoe anchor-rect mis-placement; a global mouse monitor dismisses on outside clicks, and Escape (via `cancelOperation(_:)` with a raw keyCode-53 `keyDown` fallback, wired to `onCancel` → `closePanel()`) dismisses from the keyboard. `Sources/ClaudeUsage/AppDelegate.swift`
- **UsageStore state machine and polling** — the single `ObservableObject` source of truth. `LoadState` (idle/loading/loaded/error) drives the UI; on init checks `AppCredentials.hasCredentials()` for `needsConnection`, hydrates from `UsageCache`, skips the launch fetch when the cache is fresh, and starts a 300 s timer. `refresh(force:)` guards concurrent fetches, respects `rateLimitedUntil`, and on success writes the cache and updates `lastRateLimit`. `Sources/ClaudeUsage/UsageStore.swift`
- **Token-rotation on 429 (`fetchUsageWithRefresh`)** — two-level retry: proactive refresh near expiry, refresh-and-retry once on 401, and on 429 rotate the token via `OAuth.refreshAndPersist` (cooldown-gated by `lastRefreshOnRateLimit` / `refreshOnRateLimitCooldown`=300 s) and retry once, since the usage endpoint rate-limits per access token. `Sources/ClaudeUsage/UsageStore.swift`
- **Menubar label logic (`menubarLabel`)** — returns `(text, NSColor, filled)`: for an active window with utilization>0 the active text (see below) + `UsageColor` gradient (filled = `invertMenubarColors`); unfilled `labelColor` at 0%; `0%` between sessions; and fall-through states (link emoji when `needsConnection`, hourglass when rate-limited, red `!` on error, `…` for unknown). `Sources/ClaudeUsage/UsageStore.swift`
- **Reset countdown at the limit** — when the 5-hour window is maxed (rounds to ≥100%) and `showResetTimeAtLimit` is on, the menubar shows the time until the window resets (`compactDuration`, e.g. "2h 34m") instead of a static "100%" — at the cap the reset countdown is the only actionable number left. `showResetTimeAtLimit` is a `@Published` Bool persisted to `UserDefaults` (default on), exposed in the popover's gear menu and the status-item right-click menu; the decision is the pure helper `UsageFormat.menubarActiveText(percent:resets:showResetTimeAtLimit:now:)`. `Sources/ClaudeUsage/UsageStore.swift`
- **Invert menubar colors toggle** — `invertMenubarColors`, a `@Published` Bool persisted to `UserDefaults`; when true the status item renders as a solid color-block pill, when false as colored text on clear. Exposed in the popover's gear menu and the status-item right-click menu; `AppDelegate` repaints via `objectWillChange`. `Sources/ClaudeUsage/UsageStore.swift`
- **Status-item right-click context menu** — right-clicking the menubar percentage shows a native `NSMenu` (system light/dark appearance for free) with check-marked Invert Menu Bar Colors and Show Reset Time at 100% toggles and Quit. The button sends its action on `.leftMouseUp`/`.rightMouseUp`; `togglePanel` branches on the event type, and the menu is assigned to `statusItem.menu` only for the duration of the click (detached in `menuDidClose`) so left-click keeps toggling the panel. `Sources/ClaudeUsage/AppDelegate.swift`
- **Duration and percentage formatting helpers** — `UsageFormat` provides `parseResetsAt()` (ISO8601 with/without fractional seconds), `compactDuration()` (h/m for the 5-hour window), `coarseDuration()` (d/h/m for 7-day windows), `percentString()` (round Double to integer + `%`), and `menubarActiveText()` (percent, or reset countdown at the cap). `Sources/ClaudeUsage/UsageStore.swift`

### UI
- **SwiftUI popover layout** — `PopoverView` renders a 280pt VStack gated by connection state: header + loading spinner, 5-hour section, weekly all-models section (with pace indicator), optional per-model Sonnet/Opus/Fable sections (hidden when utilization is nil; Fable is sourced from `limits[]` via `store.sevenDayFable`), and a footer. Percentages colored via `UsageColor`, times via `UsageFormat`, with a 1 s timer driving live countdowns. `Sources/ClaudeUsage/PopoverView.swift`
- **Multi-stop HSL color gradient interpolation** — `UsageColor` maps utilization (0–100) by linearly interpolating HSL across five stops: green (0%), yellow/amber (50%), orange (70%), red (90%), dark red (100%); the yellow stop differs light vs dark for legibility, returning a dynamic `NSColor` that re-resolves on appearance change. `Sources/ClaudeUsage/UsageColor.swift`
- **Canvas gauge bar with time-elapsed tick and calendar grid marks** — `UsageGauge` draws a rounded bar (fill + track), an optional vertical tick at the clock's elapsed fraction (overhangs 5pt, white-on-halo in dark mode), and optional `GridMark`s: a labeled hash at an arbitrary fraction of the bar (edge marks keep the label, skip the hash); fill past the tick = burning faster than the clock. `Sources/ClaudeUsage/UsageGauge.swift`
- **Weekly pacing analysis** — `Pace.swift` computes a `WeeklyPace` (heuristic: 7% per fully-used 5-hour session, ~14 sessions/week = 100%): `PaceCalculator.compute` projects sessions-to-max (`ceil(remaining%/7%)`) and sessions at current pace (suppressed as TBD in the first 5% of the window); `verdict` classifies maxed/tooEarly/onTrack/close/leavingOnTable and `.color` maps slack (clamped −3..+3) onto the gradient. Rendered as a colored dot + summary under the weekly section. `Sources/ClaudeUsage/Pace.swift`, `Sources/ClaudeUsage/PopoverView.swift`
- **Time-elapsed fraction and calendar-aligned grid marks** — `PopoverView.elapsedFraction` computes `(now − windowStart)/windowDuration` clamped to [0,1]; `PopoverView.calendarMarks` places a mark at every whole top-of-hour (`hourMarks`, session bar) or midnight (`weekdayMarks`, weekly bars) inside the window at that instant's elapsed fraction, labeled with the clock hour / locale-aware short weekday at the instant — so the tick reads against the marks like an axis (no grid when the window is unparseable). The session bar always labels its right edge with the reset instant — snapped to the plain hour within 5 min (absorbing the API's sub-second reset-timestamp jitter around the hour), minute-precise ("8:50p") otherwise — labels the left edge when the window starts on/near a whole hour, and drops interior marks that would crowd an edge label. Unit-tested in `GridMarkTests`. `Sources/ClaudeUsage/PopoverView.swift`
- **Footer: rate-limit status, API budget, refresh control, gear menu** — shows a live rate-limit countdown, error message on failure, API budget (requests remaining/limit/reset) when present, last-updated / next-refresh timestamps, and two same-scale borderless icon controls: a Refresh icon (`arrow.clockwise`, disabled while loading, `force:true` bypasses cooldown) and a gear menu (`gearshape`, caret hidden via `.menuIndicator(.hidden)`) holding the breakdown action ("What ate my tokens?"), Invert-menu-bar-colors and Show-reset-time-at-100% toggles, a contextual "Update available…" entry, Logout, and Quit. When an update is available a blue dot badges the gear (the separate `arrow.down.circle` button is gone). The whole row is `.focusEffectDisabled()` so the popover doesn't park a focus ring on a control at open. `Sources/ClaudeUsage/PopoverView.swift`

### Usage Breakdown
- **`WindowLog`** — append-only JSONL actor (`~/Library/Application Support/ClaudeUsage/window_log.jsonl`) recording the exact `resets_at` boundary of every `five_hour`/`seven_day`/`weekly_scoped` window the API has reported, de-duped per `(kind, model)` key so a line is appended only when the boundary changes. This is the app's only forward source of *exact* past 5h boundaries — anything before the app first observed a window is reconstructed heuristically. `Sources/ClaudeUsage/WindowLog.swift`
- **`TranscriptScanner`** — incrementally scans `*.jsonl` under `~/.claude/projects` (including `subagents/**`), resuming from a persisted byte offset per file, skipping files whose mtime predates the scan horizon, and recovering from truncated/replaced files by rescanning from 0. A `"usage"`-byte quick-reject (extended to also catch `ai-title`/user lines so the same pass can capture session titles) avoids JSON-decoding the ~85% of lines that aren't assistant-usage lines. Dedupes streamed token snapshots by `requestId` (last-wins), which is load-bearing — summing every streamed line would overcount up to ~3×. `Sources/ClaudeUsage/TranscriptScanner.swift`
- **`UsageWeights`** — the relative-cost table used to weight raw token counts for *attribution only* (not billing): token-type weights (input 1.0, output 5.0, cache-creation 1.25, cache-read 0.1) times a model-class multiplier (Opus/Fable 5.0, Sonnet/other 1.0, Haiku 0.33, synthetic excluded). `Sources/ClaudeUsage/UsageWeights.swift`
- **`WindowResolver`** — pure window-resolution: exact current/weekly/weekly-scoped ranges from the API's `resets_at`, exact past 5h ranges from `WindowLog`, and heuristic past 5h ranges reconstructed from transcript activity (a window opens on first activity after a 5h gap). Exact windows always win over an overlapping heuristic one; heuristic windows render with a `~` prefix in the UI. `Sources/ClaudeUsage/WindowResolver.swift`
- **`Aggregator`** — filters scanned events to a window's range/model-filter, groups by project (`ProjectGrouping.groupKey` collapses Conductor/worktree paths — `/.claude/worktrees/<branch>/...` — to the repo root) then by session, computes weighted costs and their normalized percentage shares, and projects those shares onto the window's server-reported `apiUtilization` as an estimated point count, with the remainder reported as `unattributedUtilizationPoints` (usage from other devices/claude.ai not captured locally). `Sources/ClaudeUsage/Aggregator.swift`
- **`UsageBreakdownService`** — the WP1↔WP2 façade actor. `availableWindows(response:now:)` enumerates the picker's timescales (current 5h, past 5h, weekly, one per scoped model); `breakdown(for:response:now:)` returns a full `BreakdownResult` for one. Holds the `TranscriptScanner`/`WindowLog`/`UsageWeights` and a per-session scan cache; it only *reads* `WindowLog`, never writes it. `Sources/ClaudeUsage/UsageBreakdownService.swift`
- **`BreakdownViewModel` / `BreakdownView` / `BreakdownWindowController`** — `BreakdownViewModel` (`@MainActor`) wraps the service, loading windows/breakdowns off-main and publishing `windows`/`selected`/`state`/`expandedProjectIDs`. `BreakdownView` (SwiftUI) renders a timescale picker (current / past 5h / weekly / per-model), an expandable per-project list with `UsageGauge` share bars and session drilldown, an "Other devices / claude.ai" row for the unattributed remainder, and a footer caveat that these are local, relative estimates. `BreakdownWindowController` hosts it in its own titled/resizable `NSWindow` (not the popover panel), lazily built and reused, activating the (accessory) app and fronting the window on each `show()`; the window subclass closes on ⌘W and Escape (no menu bar in an accessory app, so ⌘W has no Close menu item to route through). `Sources/ClaudeUsage/BreakdownViewModel.swift`, `Sources/ClaudeUsage/BreakdownView.swift`, `Sources/ClaudeUsage/BreakdownWindowController.swift`
- **Popover entry point + `UsageStore` hook** — the breakdown is reached via a "What ate my tokens?" item (`chart.bar.xaxis`) inside the footer's gear menu (`onShowBreakdown`), wired by `AppDelegate` to `BreakdownWindowController.show()`. `UsageStore.refresh()` fires `windowLog.record(usage, observedAt:)` (fire-and-forget `Task`, off the main-actor fast path) right after every successful fetch is cached, so `WindowLog` accumulates exact window boundaries passively as the app runs. `Sources/ClaudeUsage/PopoverView.swift`, `Sources/ClaudeUsage/AppDelegate.swift`, `Sources/ClaudeUsage/UsageStore.swift`

### CLI
- **Headless `--json` mode** — `CLI.parse()` detects `--json` and returns `Options` (maxAge default 360 s, `fresh` flag). `CLI.run()` is cache-first: emits a `Report` with `source="cache"` (exit 0) when the cache is younger than maxAge; otherwise `fetchFromAPI()` (same credential/refresh path as `UsageStore`, minus cooldown state), saves the cache, and emits `source="api"`. Exits 2 on not-connected; on fetch error emits stale cache with an `error` field (exit 3) or writes error JSON to stderr (exit 1). `UsageAPI.logHandle` is redirected to stderr to keep stdout pure JSON. `Sources/ClaudeUsage/CLI.swift`
- **CLI JSON report schema** — `CLI.Report` (Encodable): `source` (`cache`|`api`), `stale`, `error`, `fetched_at` (ISO8601), `age_seconds`, and per-window structs (`five_hour`, `seven_day`, `seven_day_opus`, `seven_day_sonnet`, `seven_day_fable` — the last derived from `limits[]` — `extra_usage`). `CLI.WindowReport` carries `active`, `used_percent`, `remaining_percent`, `resets_at`, `window_seconds`, `elapsed_seconds`, `remaining_seconds`; between-session windows emit `active=false` with 0%/100% and nil time fields. Output is pretty-printed, sorted keys, unescaped slashes. `Sources/ClaudeUsage/CLI.swift`

### Updates & Lifecycle
- **Alert-only update check** — `UpdateChecker` (`@MainActor ObservableObject`) compares the commit `build-app.sh` bakes into `Info.plist` as `GitCommit` against `jakeonrails/claude-usage/main` via GitHub's `GET /repos/.../compare/<build>...main` API, every 5 min and on Refresh. It publishes `available` (an `Available{aheadBy}`) only when `status == "ahead"` with `ahead_by > 0` — so dev builds (blank `GitCommit`, check disabled) and feature-branch builds (`diverged`/`behind`) never show a false alert. The pure decision is `evaluate(status:aheadBy:)` and the commit gate is `normalizedCommit(_:)`. It never runs git or touches a checkout. `PopoverView` shows a blue ↓ button whose `NSAlert` offers `UpdateChecker.updateCommand` (`git pull --ff-only && ./install.sh`) with a Copy button. `Sources/ClaudeUsage/UpdateChecker.swift`, `Sources/ClaudeUsage/PopoverView.swift`
- **Single-instance lock** — `SingleInstance.acquire()` takes a POSIX `flock` on `~/Library/Application Support/ClaudeUsage/instance.lock` right after the `--json` dispatch and before `NSApplication`; a second GUI process can't acquire it and exits 0, preventing stacked status items (macOS only de-dupes `.app` launches via LaunchServices, not raw-binary or `open` launches). The lock is held for the process lifetime and released by the kernel on exit, so it can't go stale. `--json` mode is checked first, so headless pollers never touch the lock and any number run concurrently. `Sources/ClaudeUsage/SingleInstance.swift`, `Sources/ClaudeUsage/App.swift`

## Architecture flow

**Launch.** `ClaudeUsageMain.main()` (`App.swift`) calls `CookieJar.restore()` to re-inject the Cloudflare `_cfuvid` cookie before any `URLSession`, then branches on `CLI.parse(CommandLine.arguments)`: `--json` runs `CLI.runAndExit()` and never creates `NSApplication`. For the GUI path it next calls `SingleInstance.acquire()` (exiting 0 if another menubar instance already holds the lock), then sets `.accessory` policy and hands off to `AppDelegate`, which builds the `NSStatusItem` and `PopoverPanel`, subscribes to `UsageStore.objectWillChange`, and spins up an `UpdateChecker` whose 5-min GitHub compare poll drives the popover's update button.

**Auth.** `UsageStore.init` calls `AppCredentials.hasCredentials()`. With no credentials, `needsConnection` flips true and `PopoverView` shows `ConnectAccountView`: it opens `OAuth.authorizationURL` (built from a `PKCEPair`) and exchanges the pasted `CODE#STATE` via `OAuth.exchange`, persisting the resulting tokens through `AppCredentials.save`.

**Fetch.** On a 300 s timer (and at launch when the `UsageCache` is stale), `UsageStore.refresh(force:)` runs `fetchUsageWithRefresh()`: it proactively refreshes via `OAuth.refreshAndPersist` when `ClaudeCredentials.isExpired` is true, calls `UsageAPI.fetch(accessToken:)` (with the `anthropic-beta` header and `UserAgent.string`), and retries once on 401 (refresh) or 429 (token rotation, cooldown-gated). On success `CookieJar.captureFromSharedStorage()` runs, the `UsageResponse` is written to `UsageCache`, and `lastRateLimit` is updated from `RateLimitInfo`.

**Render.** Each `objectWillChange` makes `AppDelegate.updateStatusItemTitle()` read `UsageStore.menubarLabel` and repaint the `NSStatusItem` (`UsageColor` gradient, optionally a filled pill). The `PopoverView` draws the 5-hour, weekly, and per-model windows with `UsageGauge` (tick at `elapsedFraction`), `UsageColor`, `UsageFormat`, and the `WeeklyPace` summary from `PaceCalculator`. In `--json` mode, `CLI.run()` assembles a `CLI.Report` from cache or a fresh fetch and prints it to stdout.

## Good unit-test targets

- **`UsageColor.hsl(forUsed:dark:)`** — pure HSL interpolation; assert exact H/S/L at the five stops (0/50/70/90/100) and midpoints, guarding the visual contract.
- **`HSL.toNSColor()`** — deterministic HSL→RGB math; assert sRGB components for known inputs.
- **`PKCEPair.generate()`** — pure crypto verifiable against RFC 7636 vectors: verifier is base64url of 32 bytes, challenge = base64url(SHA256(verifier)).
- **`Data.base64URLEncodedString()`** — pure transform; assert `+`/`/`/`=` map to `-`/`_`/`` (empty).
- **`ClaudeCredentials.isExpired(slack:)`** and **`expiresAt`** — pure date math against a fixed `expiresAtMs`; covers near-expiry refresh gating and nil/zero/large edge cases.
- **`OAuth.exchange` code/state split** — the `#`-split is pure string logic; test `CODE#STATE`, `CODE`, and `CODE#STATE#EXTRA`. *(covered in `AuthTests`)*
- **`OAuth.isInvalidGrantBody(_:)`** — pure JSON shape check gating the auto-disconnect branch; cover canonical payload, extra keys, other OAuth errors (`invalid_request`/`invalid_client`/etc.), malformed JSON, missing/non-string `error` field, and case sensitivity (`invalid_grant` only, not `Invalid_Grant`). *(covered in `AuthTests`)*
- **`OAuth.refreshAndPersist` `expiresAtMs` calc** — `Int64(now*1000) + expires_in*1000`; verifiable with a mocked `TokenResponse`.
- **`AppCredentials` JSON parse** — `load()` over known JSON; assert the three `expiresAt` type branches (NSNumber/Int64/Int).
- **`PopoverView.calendarMarks` / `hourMarks` / `weekdayMarks`** — pure calendar math with an injectable `Calendar`; cover hour-aligned and unaligned session windows (marks at whole hours, correct fractions), edge-label snapping (fractional-second and before-the-hour jittered `resets_at` both read as the hour), minute-precise mid-hour end labels, interior marks crowded out by edge labels, tick/mark coincidence at a known instant, weekly midnights (7 marks, correct weekdays), a midnight-aligned reset (last mark at fraction 1.0), and unparseable → nil. *(covered in `GridMarkTests`)*
- **`UsageWindow.freshUtilization(now:)`** — pure staleness guard; cover expired/future/nil-resets/nil-utilization with a controllable `now`.
- **`UsageCache` round-trip** — `save`→`load` fidelity including optional fields and ISO8601 dates; protects the cache-first CLI path.
- **`UsageResponse.scopedWeeklyWindow(modelDisplayName:)`** — the `limits[]` → per-model `UsageWindow` derivation behind the Fable meter; cover the Fable weekly_scoped match, ignoring session/weekly_all rows, unknown-model and missing-`limits` → nil, the `freshUtilization` guard on the derived window, and cache round-trip of `limits`. *(covered in `LimitsTests`)*
- **`CookieJar` staleness check** — the 86400 s `maxAge` guard in `restore()` is pure date arithmetic; protects against re-injecting stale `_cfuvid`.
- **`parseRateLimit` + 429 retry-after resolution** — header parsing plus the three-way priority (`Retry-After` → `anthropic-ratelimit-requests-reset` → 60 s) and `max(15, …)` floor; pure arithmetic over a stubbed response.
- **`UserAgent.string` format** — assert it starts with `claude-cli/` and contains `(ClaudeUsage menubar)`; a regression here causes Cloudflare 403s.
- **`UsageFormat.compactDuration` / `coarseDuration` / `parseResetsAt` / `percentString` / `menubarActiveText`** — pure formatting; table-testable across boundary values and both ISO8601 variants (incl. the ≥100%-with/without-`showResetTimeAtLimit` branch of `menubarActiveText`).
- **`CLI.parse(_:)`** — pure argument parsing; cover `--json`, `--max-age` (space and `=` forms), `--fresh`, unknown arg, `--help`, empty args.
- **`CLI.windowReport` / `CLI.report`** — pure `UsageWindow?`→`WindowReport?` and `UsageResponse`→`Report` transforms; cover active / between-sessions / nil-window cases and `source`/`stale`/`age_seconds`.
- **`AppDelegate.contrastingText(on:)`** — pure Rec.601 luma; light color → `.black`, dark red → `.white`.
- **`UsageStore.menubarLabel`** — verify each of the 7 text/color/filled branches from controlled `LoadState`/`needsConnection`/`rateLimitedUntil`/`fiveHour` inputs.
- **`PaceCalculator.compute` / `WeeklyPace.verdict` / `.slack` / `.color`** — pure pacing math; cover TBD suppression (<5% elapsed), sessions-to-max ceiling, all five verdict branches, and slack→color clamping.
- **`PopoverView.elapsedFraction` / `weekdayLabels` / `hourLabels`** — clamped fraction and locale-aware modular label arithmetic; assert the current cell matches today's symbol, 12a at midnight, 12p at noon.
- **`UpdateChecker.evaluate(status:aheadBy:)`** — pure update decision; cover `ahead`+positive → alert, `ahead`+0 → silent, and `behind`/`identical`/`diverged` → silent (no false alert on feature branches). Pair with `CompareResult` decoding from a GitHub compare fixture. *(covered in `UpdateCheckerTests`)*
- **`UpdateChecker.normalizedCommit(_:)`** — the baked-in `GitCommit` gate; nil / empty / whitespace-only → nil (disables the check for dev builds), otherwise trimmed. *(covered in `UpdateCheckerTests`)*
- **`UsageWeights.weightedCost`** — the token-type × model-class formula; cover each token type's constant, each model class's multiplier, the synthetic-zero case, and a combined mixed-token example. *(covered in `UsageWeightsTests`)*
- **`WindowResolver`** — exact current/weekly/weekly-scoped range derivation, heuristic gap-splitting from activity timestamps, exact-wins-over-heuristic merging, and the past-window cap/sort. *(covered in `WindowResolverTests`)*
